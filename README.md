# Portafolio Web - Dannis Dayana Rincón Guevara

## Descripción

Portafolio web personal desarrollado para presentar mi perfil como **Desarrolladora Web Junior Full Stack Java**, mis habilidades técnicas, proyectos y formación.

El sitio fue diseñado buscando una interfaz **clara, responsive y fácil de navegar**, permitiendo visualizar correctamente el contenido desde diferentes dispositivos.

## Objetivo

Crear un espacio profesional donde pueda presentar:

- Mi perfil profesional.
- Mis conocimientos técnicos.
- Mis proyectos de desarrollo.
- Mi formación académica.
- Mis habilidades personales.
- Mis medios de contacto.

## Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap
- JavaScript
- Git
- GitHub
